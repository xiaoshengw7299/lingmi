# 背景音乐素材库

一键成片选择「随机配乐」时，会从本目录随机挑选一个音频文件作为 BGM。

## 使用方式

把无版权 / 已获授权的音乐文件（`.mp3` `.wav` `.m4a` `.aac` `.flac` `.ogg`）直接放进这个目录即可，
无需重启服务、无需改代码。目录为空时会自动跳过配乐（不报错），前端可提示用户改选「自定义配乐」上传。

## 版权提示

请只放置你确认拥有授权（或使用许可证允许商用分发）的音乐文件，例如：
- 平台自购的商用授权音乐
- CC0 / 知识共享协议明确允许商用的公开曲库（如 Pixabay Music、Free Music Archive 的部分曲目）

本仓库不预置任何音频文件，避免引入未经核实的版权风险，需要管理员自行采购/甄别后放入。
